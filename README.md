# demo_todo_app

Node.js + Express starter (latest stable/LTS) with:
- /health endpoint
- /api/todos (in-memory demo)
- validation (zod)
- centralized error handling

## Setup
1) cp .env.example .env (or edit .env)
2) npm install
3) npm run dev

## Endpoints
- GET /health
- GET /api/todos
- POST /api/todos {"title":"..."}
